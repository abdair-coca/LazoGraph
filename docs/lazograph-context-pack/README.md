# LazoGraph — Context Pack

Este directorio contiene el contexto estratégico, de producto, UX y diseño necesario para que un agente de código pueda trabajar en LazoGraph sin tener que redescubrir la visión del producto.

## Orden de lectura recomendado

1. `CONSTITUTION.md` — reglas no negociables.
2. `PRODUCT.md` — qué es LazoGraph y por qué existe.
3. `USER_EXPERIENCE.md` — experiencia que debe provocar.
4. `INFORMATION_ARCHITECTURE.md` — navegación y estructura.
5. `DASHBOARD.md` — dirección específica del inicio.
6. `GRAPH_EXPERIENCE.md` — el grafo como protagonista.
7. `ASK_LAZO.md` — experiencia de IA y consejos.
8. `DESIGN_SYSTEM.md` — lenguaje visual.
9. `AGENTS.md` — instrucciones operativas para agentes.

## Objetivo

No construir simplemente una aplicación bonita para analizar chats.

Construir una experiencia premium de **Personal Memory Intelligence**: un asistente que puede entender la historia personal del usuario a través de sus conversaciones, encontrar conexiones y patrones, y ofrecer consejos fundamentados en evidencia verificable.

> La calidad visual debe sentirse cercana a productos como Attio, Apple y Granola, pero la experiencia debe ser propia de LazoGraph.
